# FOD historical documents

This directory contains release-specific implementation notes, dated
performance reports, compatibility baselines and other evidence retained for
traceability.

Use [`../HISTORY.md`](../HISTORY.md) as the categorized index. For current FOD
behavior and defaults start from [`../CURRENT_STATE.md`](../CURRENT_STATE.md)
and [`../README.md`](../README.md).

Historical files are intentionally preserved as recorded. Do not edit an old
measurement or release note merely to make it match a newer default; update the
current task documentation instead.
