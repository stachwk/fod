# FOD plans

This directory contains active or future planning documents. They describe
intended work, measurement sequences or proposals; they are not a statement that
the described behavior is already implemented.

For current behavior use [`../CURRENT_STATE.md`](../CURRENT_STATE.md) and the
current task guides from [`../README.md`](../README.md).

## Active direction

- [`FOD_CURRENT_ACTION_PLAN.md`](FOD_CURRENT_ACTION_PLAN.md) - ordered current
  implementation sequence.
- [`FOD_FUTURE_IDEAS.md`](FOD_FUTURE_IDEAS.md) - longer-term ideas and proposals.
- [`../../ROADMAP.md`](../../ROADMAP.md) - project roadmap.
- [`../../TODO.md`](../../TODO.md) - follow-ups, decisions and archived notes.

## Focused active/future plans

Completed design/validation plans and old execution roadmaps belong under
[`../history/`](../history/) and are indexed by [`../HISTORY.md`](../HISTORY.md).
A document moves to history when its primary purpose becomes explaining a
completed decision/result rather than directing current or future work.

Unqualified repository paths mentioned as code inside older plan text should be
read as repository-root-relative unless an explicit Markdown link says
otherwise.
